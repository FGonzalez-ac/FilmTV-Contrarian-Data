# FilmTV-Contrarian-Data
This repository makes available the data and main code described in the following paper:

"When Fiction Reflects Fiction: Contrarian Views of Climate Change in Popular Entertainment TV &amp; Films"

### Datasets

The two datasets used in the paper are available [here](https://doi.org/10.5281/zenodo.17523882) (show_dataset and movie_dataset in Version v1). The datasets are primarily divided by the source of the subtitles. The show_dataset is sourced from subslikescritp.com, while the movie_dataset is sourced from opensubtitles.org. After unzipping the file, you will find the show_dataset as a CSV file with the following fields:
<pre>'show_title', 'show_description', 'year', 'period', 'script', 'networks', 'production_companies', 'production_countries', 'genres', 'country', 'language'</pre>
The movie_dataset is a .parquet file with the following fields:
<pre>'MovieImdbID', 'imdb_id_norm', 'MovieName', 'MovieYear', 'srt_text', 'script', 'revenue', 'runtime', 'adult', 'budget', 'original_language', 'original_title', 'overview', 'popularity', 'genres', 'production_companies', 'production_countries', 'movie/show', 'tmdb_id', 'show_title'</pre>

The filtered dataset combines the episodes and movies from both datasets that contain at least one of the three main keywords ( “climate change,” “global warming,” or “climate crisis"). This dataset is available [here](https://doi.org/10.5281/zenodo.19186125) (combined_filtered_dataset in Version v1). After unzipping the file, you will find a _.parquet_ file with the following fields:
<pre>'MovieImdbID', 'imdb_id_norm', 'tmdb_id', 'movie/show', 'prod_name', 'year', 'genres', 'original_language', 'origin_countries', 'companies/networks', 'runtime', 'budget', 'original_title', 'adult', 'overview', 'popularity', 'revenue', 'srt_text', 'script', 'keywords', 'text_window', 'model', 'usage', 'logprobs', 'response', 'predicted_claims', 'verification', 'pro/neutral', 'sarcasm/mock', 'mentions', 'pro_claim', 'focus', 'anthropogenic'</pre>

The keyword list that complements the three main keywords is detailed in [`keyword_string`](/keyword_string.py). The text excerpts around these keywords are contained in the field 'text_window'. This dataset excludes productions with a special focus on climate change, which were filtered using a threshold of each excerpt's length (12,000 characters), discarding those that exceeded this number. The excerpts were passed through the contrarian identification model (CARDS 2.0). The model responses to each of the movie/episode excerpts are contained in the field 'response'. The individual contrarian discourse classification of the model can be found in 'predicted_claims'; every episode/movie that contains contrarian discourse according to the model has a value different than "0_0_0" in this field. As mentioned in the paper, the manual verification included every episode/movie flagged by the model and an additional random sample weighted on key metadata (genre, year, and original language). All the manually verified episodes and movies have a value in the field 'anthropogenic', where '0' indicates the mention(s) of the phenomenon correspond to a historical climate change, and '1' indicates the mention(s) refer to anthropogenic climate change.

Thus, the field 'verification' reflects the human validation of the model's results. The field 'pro/neutral' contains 1 of three possible values: '-1' indicates that the episode/movie ONLY contains one or more contrarian views, '1' indicates the episode/movie contains one or more pro-climate views (they can also contain contrarian views, as reflected in the field 'verification' if this is the case), and '0' indicates there is no clear view. For every episode/movie with pro-climate views, the field 'pro_claim' contains the sentences or phrases that can be considered as pro-climate, and the field 'focus' classifies them between 'impacts', 'solutions', or 'both' depending on what their focus is on. Finally, the field 'sarcasm/mock' registered whether or not the contrarian view can be interpreted as ironically expressed or disqualified.
